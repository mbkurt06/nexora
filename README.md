# Nexora

Nexora is a mobile-first, Turkish-language personal news reader and Progressive Web App (PWA).

## Goals

- Explore technology, science, world affairs, and social media news by topic.
- Read balanced summaries with dates and source links.
- Mark stories as read and save stories for later.
- Review each story in ChatGPT by copying grounded context and opening ChatGPT.
- Support a voice-conversation workflow in the ChatGPT app, subject to iOS/app limitations.
- Deploy with Vercel and optionally store stories in Supabase.

The first version works with sample editorial data without requiring API keys. No unpublished or unverified stories should be presented as live news.
